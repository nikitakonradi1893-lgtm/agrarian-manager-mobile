AGRARIAN MANAGER MOBILE v1.2 (PWA)

Это полная мобильная сборка на базе Agrarian Manager v1.1.

Установка на iPhone:
1. Загрузите содержимое этой папки в корень каталога GitHub Pages (или другого HTTPS-хостинга).
2. Откройте адрес в Safari, дождитесь загрузки.
3. Нажмите Поделиться → На экран «Домой» → Добавить.
4. Откройте приложение с домашнего экрана.
5. После первой полной загрузки игра может работать офлайн через Service Worker.

Не открывайте index.html непосредственно через Файлы: для установки и кеша требуется HTTPS.
Сохранение хранится в браузерном хранилище этого сайта и отдельно от Windows-версии.
Сделайте экспорт сохранения перед очисткой данных Safari.
